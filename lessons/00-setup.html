下載練習程式

先準備好 Git、Python 3.10 以上版本，以及已登入的 IBM Bob。COBOL 解讀會使用 Premium Package for Z（pp4z）。

  1. 在 VSCode 按 Ctrl+Shift+P，選擇 Git: Clone。macOS 使用 ⌘⇧P。
  2. 貼上下方網址，選擇儲存位置，下載完成後按 Open。
  3. 從左下角的分支選單切換到 workshop/tcb-2026。
Repository 網址
https://github.com/nicholas-yahung-chien/tcb-bob-workshop.git

也可以下載 ZIP，解壓後用 File → Open Folder 開啟。

從 Bob 對話開始

開啟 IBM BOB 面板，按「＋」建立新對話。輸入框下方可以選擇 Ask、Plan、Agent，以及 pp4z 的 Z Code、Z Architecture。

每個練習會列出要用的檔案。輸入 @ 後選取檔案，或從檔案總管拖進對話，再送出問題。遇到 Permissions 提示時，看看 Bob 想讀取、修改或執行什麼，再核准操作。

同一段對話已加入的檔案，不必每一步重複加入。若改開新對話，請把該步列出的需求、程式與已有成果一起補上。

換成自己的問題，也可以這樣問

把工作交給 Bob 時，可以像向同事說明需求一樣，交代下面幾件事。不必每次都重新寫一遍；同一段對話已經說清楚的內容，可以接著使用。

想一想可以怎麼說
背景：我正在做什麼？我剛接手這支程式。
任務：我想弄清楚什麼？想知道它如何處理一筆資料。
依據：請根據什麼回答？請根據附上的程式，指出對應段落。
成果：我希望看到什麼？依處理順序說明，另外列出需要補充的資料。

看完回答還不明白，就接著問：「可以用一筆資料舉例嗎？」需要留下文件時，再補上用途和格式。下一個單元也會用 Enhance prompt 試著補充提問，再比較哪些內容值得保留。

找到 pp4z 的功能

選擇 Z Code，點 Bob 面板上方的播放圖示 Start Workflow，看看清單裡是否有 Explain code 和 Generate documentation。接下來會用到這兩個功能。

如果找不到，先看常見問題。部分版本會將 Z Architecture 顯示為 Z Architect。
