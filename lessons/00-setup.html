下載練習程式

先確認 IBM Bob 已安裝並登入，COBOL 解讀會使用 Premium Package for Z（pp4z），主機連線使用 Zowe Explorer。下列工具是本課程實作的額外條件，不能因為已安裝 Bob 就視為已備妥。

工具什麼時候需要準備方式
Git使用 Git: Clone 下載與切換分支時另行確認本機可執行 Git；若使用下方 ZIP 下載，可不安裝 Git
Python 3.10 以上檢查教材、準備 .cbl 檔、產生主機 JCL，以及執行 Python 延伸練習時另行安裝或使用本機既有的 Python；本課程只用標準庫，不需 pip 安裝套件

3.10 是 Python 3 的第 10 個次版本，不是 3.1。只閱讀程式或設定 Zowe 連線不需要執行 Python，但後續教材準備與 JCL 產生步驟需要它。Bob 的執行功能會呼叫本機工具，不會取代 Git 或 Python。

在 Bob 的終端機執行 git --version（使用 Git 下載者），以及 python --version；Windows 也可用 py -3 --version，macOS／Linux 可用 python3 --version。確認 Python 為 3.10 以上。若找不到，先依電腦的安裝規範備妥工具，再繼續。可從 Git、Python 官方網站取得安裝程式。

  1. 在 VSCode 按 Ctrl+Shift+P，選擇 Git: Clone。macOS 使用 ⌘⇧P。
  2. 貼上下方網址，選擇儲存位置，下載完成後按 Open。
  3. 從左下角的分支選單切換到 workshop/tcb-2026。
Repository 網址
https://github.com/nicholas-yahung-chien/tcb-bob-workshop.git

不使用 Git 時，可以直接下載教材 ZIP，解壓後用 File → Open Folder 開啟。ZIP 已包含完整教材、host-lab、zowe.config.json 與 zowe.schema.json，不需另取連線設定；ZIP 使用者不必切換分支。

從 Bob 對話開始

主機練習會使用個人 z/OSMF 帳號與 Zowe Explorer。完成下方工作區準備後，再設定自己的主機連線。

開啟 IBM BOB 面板，按「＋」建立新對話。輸入框下方可以選擇 Ask、Plan、Agent，以及 pp4z 的 Z Code、Z Architecture。

每個練習會列出要用的檔案。在輸入框輸入 @，從彈出的清單找到並點選檔案，再送出問題。清單支援搜尋時，可輸入檔名縮小範圍，確認路徑後選取。單純貼上 @檔案路徑 不代表已加入檔案。遇到 Permissions 提示時，看看 Bob 想讀取、修改或執行什麼，再核准操作。

同一段對話已加入的檔案，不必每一步重複加入。若改開新對話，請把該步列出的需求、程式與已有成果一起補上。

換成自己的問題，也可以這樣問

把工作交給 Bob 時，可以像向同事說明需求一樣，交代下面幾件事。不必每次都重新寫一遍；同一段對話已經說清楚的內容，可以接著使用。

想一想可以怎麼說
背景：我正在做什麼？我剛接手這支程式。
任務：我想弄清楚什麼？想知道它如何處理一筆資料。
依據：請根據什麼回答？請根據附上的程式，指出對應段落。
成果：我希望看到什麼？依處理順序說明，另外列出需要補充的資料。

看完回答還不明白，就接著問：「可以用一筆資料舉例嗎？」需要留下文件時，再補上用途和格式。下一個單元也會用 Enhance prompt 試著補充提問，再比較哪些內容值得保留。

準備自己的主機連線

教材根目錄已附上 zowe.config.json 與 zowe.schema.json。開啟設定檔，把唯一的 YOUR_USER_ID 換成自己的帳號，保留雙引號並儲存；其餘設定不需修改。

在 Zowe Explorer 選取 tcb-zosmf，透過認證介面輸入密碼，再確認自己的 JOBS 與資料集。若尚未顯示連線，執行 Developer: Reload Window。本步直接使用教材設定，不需要請 Bob 建立 profile。

本次個人 profile 使用 rejectUnauthorized: false，不需另外設定 CA；HTTPS 仍加密，但不驗證伺服器憑證，不應套用到正式系統。設定檔存在不代表已登入主機。

依教材中的 host-lab/CONNECTION.md 設定連線，確認 JOBS owner 是自己，並將不含密碼的配置寫入 output/host-lab/environment.md。主機位址使用本場提供的資料。

兩場使用不同帳號，成果可以分開保留。若下載後沒有 host-lab，先取得包含主機練習的教材版本，再進行CKP02 主機實作。

找到 pp4z 的功能

選擇 Z Code，點 Bob 面板上方的播放圖示 Start Workflow，看看清單裡是否有 Explain code 和 Generate documentation。接下來會用到這兩個功能。

如果找不到，先看常見問題。部分版本會將 Z Architecture 顯示為 Z Architect。
