# 網站與教學設計

參考來源：<https://hw.is-a.dev/ibm-bobathon/> 與 <https://github.com/howard-haowen/ibm-bobathon>，於2026/09/10研究。

採用其Hub→工作坊→編號教學頁→參考成果的閱讀層級，以及可複製Prompt、預期回應、Ask→Plan→Agent的進程。版面使用IBM Plex、300字重標題、IBM Blue、白灰表面、方角細框與行動版重排。

本站依合庫來源重新編寫內容，不複製參考專案的業務事實。下載區採獨立workshop分支；Pages部署改用官方artifact方式從site/發布，沒有直接沿用參考repo的gh-pages覆寫腳本。

需求規劃與COBOL單元共享CKP02主線；CIS14提供較完整的真實copybook/IMS延伸題。固定輸出路徑與可驗收事實，避免讓模型自由生成無法比較的成果。使用者確認可公開原始碼後，完整45份TXT以原始bytes與閱讀版提供；工作單用空白模板。

語意驗收與程式測試分開：機器檢查文件結構、欄位事實、引文存在與測試；人檢查來源支持、因果、缺件及操作可行性。僅靠Bob兩次都回答相同不算正確。
