1. 核對自己的程式與作業

本單元約 20 分鐘。先完成主機連線。在 Zowe Explorer 的「資料集」選取目前教材工作區的 tcb-rse，搜尋 <自己的帳號>.TCBLAB.*。

  1. 展開 TCBLAB.COBOL，確認有 CKP02、GENCKP、CHKCKP，開啟 CKP02 核對中文註解與換行。
  2. 展開自己的 TCBLAB.JCL，在 RUN 按右鍵選 Download Member...，下載到 host-lab/run.jcl。下載選項取消 Generate Directory Structure 與 Use Uppercase Names，勾選 Override File Extension 並填入 jcl；取消 Overwrite。已有個人檔案時先核對，不覆寫。
  3. 使用下方提問，讓 Bob 讀取下載的 JCL 與 environment.md，核對帳號、作業名稱與步驟。

Agent 模式

檔案位置（供核對）：host-lab/BOB-GUIDE.md、host-lab/environment.md、host-lab/run.jcl、z-tests/run.jcl

一起看這份主機作業
這是主機上已經幫我準備好的作業，我把個人版本另存成 run.jcl 了。請和教材的同名 run.jcl 範本比較，保留個人帳號設定。請依 BOB-GUIDE.md 和我的 environment.md，帶我看它會編譯哪幾支程式、怎麼準備測試資料，以及如何確認結果。也幫我核對是不是使用我自己的帳號，將檢查結果記在 host-lab/jcl-review.md。先不要提交。
預期回應

作業步驟與個人配置的說明，以及 host-lab/jcl-review.md 的核對結果。

Job 名稱應為自己的帳號加 A，使用 DEVVS1、SCNOSMS。CGEN、CCKP、CCHK 應讀取自己的 GENCKP、CKP02、CHKCKP。保留 CODEPAGE(937),DBCS 編譯選項。

2. 提交作業並下載紀錄

  1. 在核對過的本機 JCL 編輯器按右鍵，選 Submit as JCL，使用 tcb-rse（IBM-1371）。
  2. 記下回傳的 job ID。在「工作」將 Owner 設為自己的帳號，Prefix 與 Status 設為 *，找到該作業並等待完成。提交逾時時先查詢，不立即重送。
  3. 對完成的 JOB 按右鍵 → 全部下載，存到工作區，例如 host-lab/logs/<job ID>/。保留下載的檔名與目錄結構，不選二進位下載。
  4. 開啟 GENERATE／PRINTDD 確認中文可讀。若有亂碼，從 tcb-rse 開啟該 DD，載入完整內容並另存 UTF-8 副本。

將完整作業資料夾帶到下一單元。作業顯示 CC 0004 時，先查看是哪個步驟回傳，再判斷結果。
