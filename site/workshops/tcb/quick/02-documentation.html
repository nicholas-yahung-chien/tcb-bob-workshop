COBOL 文件化 · 簡易版

把程式讀懂，也讓下一個人看得懂

用工作流程解讀 CKP02，產生文件並對照程式。

簡易版 · 課程安排 · 查看完整版

1. 請 Bob 帶你讀 CKP02

本單元約 20 分鐘。沿用上一單元的 Local Metadata 與 DD.json，切換到 Z Code，點 Start Workflow → Explain code，選擇目前工作區與 z-lab/CKP02.cbl。

在 Bob Settings → Skills 確認 cobol-explain-zh-tw 已啟用。依工作流程閱讀程式的輸入、轉換條件與輸出，找到對應的程式段落。

2. 產生文件，再對照程式

從 Start Workflow → Generate program documentation 選擇 CKP02。完成後開啟結果連結，將實際產生的文件與 DD.json 加入對話，再使用下方提問。

Z Code 模式

檔案位置（供核對）：z-lab/CKP02.cbl

一起核對文件
請對照 CKP02.cbl，帶我看剛才 Generate program documentation 產生的文件。挑一筆會轉換、一筆不會轉換的資料，說明它們怎麼走過程式；文件和程式對不起來的地方，也請指出來。
預期回應

兩種處理情況的程式依據，以及文件需要調整的地方。

保留工作流程產生的文件。若說明與程式不符，先確認對應段落，再請 Bob 修正文件；未能確認的欄位用途保留為問題。
