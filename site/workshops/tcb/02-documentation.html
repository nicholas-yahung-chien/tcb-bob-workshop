核對程式解釋 · Z Code
請根據目前的Explain結果，重新核對output/z-lab/CKP02.cbl與bank-source/reading/CKP02.TXT。
1. 以實際行號說明IF句點、REWRITE與下一筆READ的範圍。
2. 列出R-ID群組、R-ID-1、R-ID-2、R-NAME的起訖位置；REDEFINES不重複計算。
3. 以0012345678及0000123456示範轉換與再次執行，標出兩個空白的位置。

只解釋，不改程式。不要從程式名稱、修訂碼或硬體名稱推斷未證實的歷史與環境。

IF的句點在84行結束；86行REWRITE不受該IF限制。R-ID群組為11位，R-NAME位於12–51，因此14–16位的EOF檢查在R-NAME內。主機code page與外部備份設定仍待確認。
