用測試確認 Bob 的實作

將規格落成可執行的行為模型，保留主機驗證的界線。

15分鐘的必做實作

15:47–15:50閱讀介面與測試；15:50–15:58請Bob實作並執行；15:58–16:02核對結果或以修正Prompt處理失敗。此次新增的dry-run功能落在Python行為模型，原始CKP02保持不變。

model使用ASCII bytes：COBOL第14位是Python索引13。不要用Unicode中文字數驗證主機byte欄位，也不要把模型的written計數等同於CKP02的REWRITE次數。

輸入／模式預期
0012345678，無EOF12345678加兩空白，尾390 bytes不變
14–16位是EOF內容不變，批次仍處理下一筆
非00前綴內容不變
4筆中2筆符合，dry-runtotal=4, changed=2, written=0，回原資料副本
相同資料，write模型changed=2, written=2，回轉換副本
非法長度或型別ValueError，全批先驗證

Step 1 · 請Bob寫程式與測試

從契約到測試 · Agent
請閱讀 AGENTS.md、specs/change-request.md、samples/cobol/IDSHIFT.cbl、IDREC.cpy、samples/python/normalizer.py 及 tests/test_normalizer.py。
使用Agent，在output/normalizer.py完成transform與process，完全依CR-01介面契約；只用Python標準庫，不做任何I/O，不改來源或測試。
在output/test_authored.py額外撰寫三個unittest即可：測完整record保留、資料中EOF仍可處理下一筆、dry-run不改caller資料；不要只檢查回傳型別，也不要增加不必要的測試數。
再執行 python scripts/verify.py unit，若失敗修正output/程式再執行。不得修改scripts/、tests/、specs/來過關。
特別核對eligible與changed的定義；本題兩者相等，written表示模型套用筆數而不是實體REWRITE次數。空資料、非法長度、型別錯誤、尾端任意bytes都要處理。
完成後用檔案編輯工具寫output/test-report.md，約300中文字：實際命令、通過或失敗、失敗原因與修正、尚未執行的COBOL/IMS驗證。不捏造執行紀錄。避免以PowerShell字串插值寫入Markdown，以免反引號破壞內容。

Step 2 · 獨立驗收

python scripts/verify.py unit

提供11個獨立測試方法，另要求學員產出至少3個測試。測試包含400 bytes全記錄比對、EOF位置偏一、尾端任意bytes、caller不變及重跑。不要用「程式跑完沒有錯」代替結果核對。

為什麼要測重跑？

0000123456第一次成為00123456加兩空白，仍以00開頭；第二次會再次改變。因此本規則不保證冪等，正式批次的重跑與備份回復必須先規劃。

Step 3 · 失敗就帶證據修正

根據驗收修正 · Agent
請閱讀這次驗收輸出、specs/change-request.md和相關原始素材，逐項修正output/的產出。
先指出失敗項目、對應規格、來源證據，再做最小修改；不可更改tests/、scripts/、samples/或specs/。
修正後重跑相同驗收命令。區分測試實際通過、人工待審與環境未驗證，不把檔案存在當成內容正確。
若遇到缺件或服務逾時，保留目前輸出，依reference/的備援答案進行人工比對；不要宣稱重跑成功。

格式核對：marker_field只放欄位名稱R-NAME，說明寫在JSON外；id_bytes指R-ID-1的10位，不是R-ID群組11位。JSON只保留契約指定的鍵，不加註解欄位。引文直接取原始行的文字片段。
用原文檔案編輯工具修復Markdown反引號與控制字元，不使用PowerShell雙引號字串拼接Markdown。人工核對主機code page、資料集組織、外部備份與鎖定都屬未提供；不把未知改寫成確定不存在。IDSHIFT會改記憶體，無I/O不等於已具dry-run。
若需要查看驗收實作，只讀scripts/verify.py；不得更改驗收標準。最後再次執行對應命令並回報實際結果。

延伸 · 真正COBOL測試driver

具GnuCOBOL的個人練習環境可編譯合成IDSHIFT與TESTSHIFT。下列不是IBM Enterprise COBOL編譯指令，本次製作環境沒有COBOL編譯器，因此此路徑尚未實測。

cobc -x -fixed -I samples/cobol -o output/testshift samples/cobol/TESTSHIFT.cbl samples/cobol/IDSHIFT.cbl
# Windows: .\output\testshift.exe
# macOS/Linux: ./output/testshift

正式主機單元測試由Jackson／平台團隊確認編譯器、JCL、執行程式庫、code page與測資後另行執行。
