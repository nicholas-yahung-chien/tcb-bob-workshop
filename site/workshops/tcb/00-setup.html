開始之前

開啟你的練習工作區

下載程式，和 Bob 一起準備開始。

下載練習程式

準備已登入的 IBM Bob、Premium Package for Z（pp4z）與 Zowe Explorer。本課程主流程不需要安裝 Python：將 Markdown 指引交給 Bob，完成教材檢查、JCL 準備與主機測試紀錄分析。

使用 Git: Clone 下載時才需要本機 Git；也可以直接下載 ZIP，省去 Git 安裝。程式與資料比對在主機執行，Bob 會依實際紀錄確認結果。

使用 Git 時，在預計存放教材的位置開啟終端機，執行下方指令，直接取得 workshop/tcb-2026 教材分支。完成後在 Bob 用 File → Open Folder 開啟下載的資料夾。

下載教材分支
git clone --branch workshop/tcb-2026 --single-branch --depth 1 https://github.com/nicholas-yahung-chien/tcb-bob-workshop.git

不使用 Git 時，可以直接下載教材 ZIP，解壓後用 File → Open Folder 開啟。ZIP 已包含完整教材、host-lab、zowe.config.json 與 zowe.schema.json，不需另取連線設定；ZIP 使用者不必切換分支。

從 Bob 對話開始

主機練習會使用個人 z/OSMF 帳號與 Zowe Explorer。完成下方工作區準備後，再設定自己的主機連線。

開啟 IBM BOB 面板，按「＋」建立新對話。輸入框下方可以選擇 Ask、Plan、Agent，以及 pp4z 的 Z Code、Z Architecture。

每個練習會列出要用的檔案。在輸入框輸入 @，從彈出的清單找到並點選檔案，再送出問題。清單支援搜尋時，可輸入檔名縮小範圍，確認路徑後選取。單純貼上 @檔案路徑 不代表已加入檔案。遇到 Permissions 提示時，看看 Bob 想讀取、修改或執行什麼，再核准操作。

同一段對話已加入的檔案，不必每一步重複加入。若改開新對話，請把該步列出的需求、程式與已有成果一起補上。

換成自己的問題，也可以這樣問

把工作交給 Bob 時，可以像向同事說明需求一樣，交代下面幾件事。不必每次都重新寫一遍；同一段對話已經說清楚的內容，可以接著使用。

想一想可以怎麼說
背景：我正在做什麼？我剛接手這支程式。
任務：我想弄清楚什麼？想知道它如何處理一筆資料。
依據：請根據什麼回答？請根據附上的程式，指出對應段落。
成果：我希望看到什麼？依處理順序說明，另外列出需要補充的資料。

看完回答還不明白，就接著問：「可以用一筆資料舉例嗎？」需要留下文件時，再補上用途和格式。下一個單元也會用 Enhance prompt 試著補充提問，再比較哪些內容值得保留。

請 Bob 幫忙檢查檔案

workspace.md 寫好了環境與教材完整性檢查步驟。你可以像請同事照著作業說明操作一樣，把這份文件交給 Bob。

Agent 模式

加入檔案：specs/workspace.md

檢查工作區
請依 specs/workspace.md 幫我檢查環境，準備這次要用的程式檔案。完成後告訴我應該開啟哪個檔案。
預期回應

環境檢查結果，以及準備好的 CKP02.cbl 位置。

完成後，開啟 output/z-lab/CKP02.cbl。程式已隨教材放在 output/z-lab，不需要轉檔；檢查報告會存到 output/workspace-check.md。

準備自己的主機連線

接下來，用分配給你的帳號登入主機，查看自己的資料集與作業。教材已備妥連線設定，你只需要填入帳號，再於登入時輸入密碼。

  1. 開啟教材根目錄的 zowe.config.json，將 YOUR_USER_ID 換成自己的帳號，保留雙引號並儲存。其餘欄位維持原值。
  2. 開啟 Zowe Explorer，在「資料集」展開 tcb-zosmf。出現密碼欄位時，輸入分配給你的密碼並按 Enter；密碼只在此輸入，不貼到 Bob 對話或教材檔案。
  3. 點選連線旁的搜尋圖示，輸入 <自己的帳號>.TCBLAB.*。例如帳號是 TCB2101，就輸入 TCB2101.TCBLAB.*。
  4. 在「工作」（JOBS）選取同一個連線，將 Owner 設為自己的帳號，查看自己的作業清單。

查詢完成且沒有認證或連線錯誤，就可以繼續。新帳號的清單可能是空的；稍後提交 CKP02 後，就能在這裡找到自己的作業。

找不到連線，或登入時遇到問題？

若沒有顯示 tcb-zosmf，按 Ctrl+Shift+P，執行 Developer: Reload Window，再開啟 Zowe Explorer。若仍有錯誤，保留完整訊息，依 host-lab/CONNECTION.md 的說明檢查。

本練習不需另外安裝 CA 憑證。教材的連線設定保留 HTTPS 加密，但略過伺服器憑證驗證，僅供本次練習使用。

建立個人作業配置

確認已能查詢自己的資料集與作業後，請 Bob 把帳號和作業配置記成一份文件。output/host-lab/environment.md 會在這一步建立，現在還看不到它是正常的。

Agent 模式

加入檔案：host-lab/CONNECTION.md

記下我的作業配置
我已用自己的帳號查詢到主機資料集與作業。請依 host-lab/CONNECTION.md，幫我建立 output/host-lab/environment.md，完成後列出內容讓我核對。只記錄個人作業配置，不要修改連線設定或提交作業。
預期回應

output/host-lab/environment.md

完成後，開啟 output/host-lab/environment.md，核對以下內容：

  • 帳號與你登入 Zowe 的帳號一致，連線名稱為 tcb-zosmf。
  • Job 名稱為自己的帳號加 A，例如 TCB2101A。
  • Volume 為 DEVVS1，Storage class 為 SCNOSMS。
  • 文件沒有待填文字或密碼。

進行 CKP02 主機實作時，Bob 會使用這份文件準備你的 JCL。

找到 pp4z 的功能

  1. 在 IBM BOB 面板選擇 Z Code，點上方的播放圖示 Start Workflow。
  2. 出現「選擇工作區以執行此工作流程」時，選擇 Run Workflow in〈你開啟的教材資料夾名稱〉，核對下方路徑是你解壓並開啟的本機教材資料夾。選項名稱會隨你開啟的資料夾而不同。本次閱讀本機程式，請選本機路徑。
  3. 進入 Bob workflows 清單後，找到 Explain code 與 Generate program documentation。

找到這兩個功能即可完成本步。進行程式文件單元時，再點對應項目右側的 Start。

如果找不到，先看常見問題。部分版本會將 Z Architecture 顯示為 Z Architect。
