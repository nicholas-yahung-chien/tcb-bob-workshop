下載練習程式

本次主機操作統一使用 tcb-rse（IBM-1371），透過 Zowe Explorer 閱讀來源、JCL 及中英文作業紀錄。

準備已登入的 IBM Bob、Premium Package for Z（PPZ）與 Zowe Explorer。本課程主流程不需要安裝 Python：將 Markdown 指引交給 Bob，完成教材檢查、JCL 準備與主機測試紀錄分析。

使用 Git: Clone 下載時才需要本機 Git；也可以直接下載 ZIP，省去 Git 安裝。程式與資料比對在主機執行，Bob 會依實際紀錄確認結果。

使用 Git 時，在預計存放教材的位置開啟終端機，執行下方指令，直接取得 workshop/tcb-2026 教材分支。完成後在 Bob 用 File → Open Folder 開啟下載的資料夾。

下載教材分支
git clone --branch workshop/tcb-2026 --single-branch --depth 1 https://github.com/nicholas-yahung-chien/tcb-bob-workshop.git

不使用 Git 時，可以直接下載教材 ZIP，解壓後用 File → Open Folder 開啟。ZIP 已包含完整教材、host-lab、zowe.config.json 與 zowe.schema.json，不需另取連線設定；ZIP 使用者不必切換分支。

從 Bob 對話開始

主機練習會使用個人主機帳號，透過 Zowe Explorer 的 IBM RSE API 連線開啟程式、提交作業與查看紀錄。完成下方工作區準備後，再設定自己的主機連線。

開啟 IBM BOB 面板，按「＋」建立新對話。輸入框下方可以選擇 Ask、Plan、Agent，以及 PPZ 的 Z Code、Z Architect。

提示詞已寫入需要的檔名，選好模式後可以直接複製提問，讓 Bob 從目前工作區找檔案。若找到同名檔案，請確認它使用的是本次練習版本。

工作流程產生的文件或下載的作業紀錄，檔名可能不同；請告訴 Bob 實際檔名或 job ID。若仍找不到，再輸入 @，從清單選取檔案或資料夾。同一段對話已確認的檔案，不必重複加入。遇到 Permissions 提示時，確認 Bob 要讀取或修改的內容，再核准操作。

換成自己的問題，也可以這樣問

把工作交給 Bob 時，可以像向同事說明需求一樣，交代下面幾件事。不必每次都重新寫一遍；同一段對話已經說清楚的內容，可以接著使用。

想一想可以怎麼說
背景：我正在做什麼？我剛接手這支程式。
任務：我想弄清楚什麼？想知道它如何處理一筆資料。
依據：請根據什麼回答？請根據附上的程式，指出對應段落。
成果：我希望看到什麼？依處理順序說明，另外列出需要補充的資料。

看完回答還不明白，就接著問：「可以用一筆資料舉例嗎？」需要留下文件時，再補上用途和格式。想調整提問時，也可以用 Enhance prompt 看看哪些補充值得保留。

請 Bob 幫忙檢查檔案

workspace.md 寫好了環境與教材完整性檢查步驟。你可以像請同事照著作業說明操作一樣，把這份文件交給 Bob。

檢查工作區
請依 workspace.md 幫我檢查環境，準備這次要用的程式檔案。完成後告訴我應該開啟哪個檔案。
預期回應

環境檢查結果，以及準備好的 CKP02.cbl 位置。

完成後，開啟 z-lab/CKP02.cbl。程式已隨教材放在 z-lab，不需要轉檔；檢查報告會存到 output/workspace-check.md。

準備自己的主機連線

第一次在新教材工作區開啟 Zowe Explorer 時，既有連線可能會顯示，但教材的 tcb-rse 尚未加入清單。先完成下方帳號設定；若「資料集」沒有 tcb-rse，點該區塊的 ＋（Add profile），選擇帶資料夾圖示、屬於目前教材工作區的 tcb-rse。出現是否適用所有目錄結構的詢問時，選擇是，再確認「資料集」與「工作」都有 tcb-rse。這是將教材已有的連線加入清單，不需要建立另一份設定檔。

接下來，用分配給你的帳號登入主機，查看自己的資料集與作業。教材已備妥連線設定，選好帳號後，可以請 Bob 幫你填入登入資訊。

每個帳號的密碼都使用相同規則：將帳號的第一個字母保留大寫，其餘英文字母改成小寫，再接上 TCBBob@2026。例如帳號 TCB2101 的密碼是 Tcb2101TCBBob@2026。下方步驟會將密碼以明文存入自己的本機設定檔；這份個人設定不要上傳或分享。

選擇並登記學員帳號

展開下方共用表格，找一個姓名欄仍空白的帳號，並在同一列填入自己的姓名。每個帳號只供一位學員使用；若已有人填寫，請改選其他空白帳號。

在新分頁開啟共用表格

把下方的「〈填入帳號〉」換成剛才選定的帳號，再交給 Bob。密碼會依上方規則填入，不必另外輸入。

Agent 模式

檔案位置（供核對）：host-lab/CONNECTION.md

幫我設定主機帳號
我選的帳號是〈填入帳號〉。請依 CONNECTION.md，幫我把帳號和密碼直接填進這個工作區的 zowe.config.json，讓我可以用 Zowe Explorer 登入。完成後告訴我怎麼查看自己的資料集和作業。
預期回應

完成本機工作區的帳號密碼設定，並說明手動查詢方式；回覆不顯示密碼。

  1. 完成後，開啟 Zowe Explorer，選擇目前教材工作區的 tcb-rse。若仍要求輸入密碼或顯示舊帳號，依 host-lab/CONNECTION.md 檢查實際使用的設定。
  2. 在「資料集」點連線旁的搜尋圖示，輸入 <自己的帳號>.TCBLAB.*，例如 TCB2101.TCBLAB.*。
  3. 在「工作」（JOBS）選擇 tcb-rse，將 Owner 設為自己的帳號，Prefix 與 Status 設為 *。
  4. 核對目前連線使用的帳號與選定帳號一致。篩選器只決定查詢範圍，不會切換登入身分。

查詢完成且沒有認證或連線錯誤，就可以繼續。資料集清單應包含 <自己的帳號>.TCBLAB.COBOL 與 <自己的帳號>.TCBLAB.JCL，裡面已準備好練習程式與個人作業。作業清單可能是空的；稍後提交 CKP02 後，就能在這裡找到自己的作業。

找不到連線，或登入時遇到問題？

若「資料集」或「工作」沒有顯示 tcb-rse，先點「資料集」的 ＋（Add profile），選擇帶資料夾圖示的教材工作區 tcb-rse，並在詢問時選擇適用所有目錄結構。如果連加入清單也找不到它，再確認開啟的是含 zowe.config.json 的教材根目錄，且 IBM Z Open Editor 與 Zowe Explorer 已啟用；按 Ctrl+Shift+P，執行 Developer: Reload Window 後重試。若仍有錯誤，保留完整訊息，依 host-lab/CONNECTION.md 的說明檢查。

本練習不需另外安裝 CA 憑證。教材的連線設定保留 HTTPS 加密，但略過伺服器憑證驗證，僅供本次練習使用。

建立個人作業配置

確認已能查詢自己的資料集與作業後，請 Bob 把帳號和作業配置記成一份文件。host-lab/environment.md 會在這一步建立，現在還看不到它是正常的。

Agent 模式

檔案位置（供核對）：host-lab/CONNECTION.md

記下我的作業配置
我已用自己的帳號查詢到主機資料集與作業。請依 CONNECTION.md，幫我建立 host-lab/environment.md，完成後列出內容讓我核對。只記錄個人作業配置，不要修改連線設定或提交作業。
預期回應

host-lab/environment.md

完成後，開啟 host-lab/environment.md，核對以下內容：

  • 帳號與你登入 Zowe 的帳號一致，來源連線為 tcb-rse（IBM-1371），作業連線為 tcb-rse（IBM-1371）。
  • 來源資料集為 <自己的帳號>.TCBLAB.COBOL(CKP02)，本機來源為 z-lab/CKP02.cbl。
  • Job 名稱為自己的帳號加 A，例如 TCB2101A。
  • Volume 為 DEVVS1，Storage class 為 SCNOSMS。
  • 文件沒有待填文字或密碼。

進行 CKP02 主機實作時，Bob 會使用這份文件核對主機上已準備好的 JCL。

找到 PPZ 的功能

  1. 在 IBM BOB 面板選擇 Z Code，點上方的播放圖示 Start Workflow。
  2. 出現「選擇工作區以執行此工作流程」時，選擇 Run Workflow in〈你開啟的教材資料夾名稱〉，核對下方路徑是你解壓並開啟的本機教材資料夾。選項名稱會隨你開啟的資料夾而不同。本次閱讀本機程式，請選本機路徑。
  3. 進入 Bob workflows 清單後，找到 Explain code 與 Generate program documentation。

教材已附上 Explain code 與可閱讀資料字典使用的中文技能。開啟 Bob Settings → Skills，確認 cobol-explain-zh-tw 與 data-dictionary-zh-tw 均顯示為 Workspace，且 Active 已開啟。檔案存在不代表技能已啟用，請以此畫面確認。教材中的 program-docs-zh-tw 僅供需要翻譯英文正文時備用，主流程不需呼叫。

找到這兩個功能即可完成本步。進行程式文件單元時，再點對應項目右側的 Start。

如果找不到，先看常見問題。

最後，讓 Bob 認識這個工作區

切換到 Z Code，在對話中輸入 /init，讓 Bob 整理程式結構與工作區規則。教材已有 AGENTS.md，請保留原有練習規則，再補上這次掃描取得的資訊。

初始化工作區
/init

完成後檢查 AGENTS.md 的變更，確認保留原始程式的要求仍在，且沒有寫入帳號密碼。若出現不符合教材的規則，請 Bob 修正後再繼續。操作說明可參考 IBM 的 /init 指引。
