準備工作區

本課程使用VSCode中的IBM Bob對話面板與IBM Bob Premium Package for Z（pp4z）。請先完成帳號登入，確認pp4z已啟用，並備妥Git與Python 3.10以上。實作只使用Python標準庫。

Step 1 · 下載並開啟教材

  1. 在VSCode按Ctrl+Shift+P（macOS：⌘⇧P），選擇Git: Clone。
  2. 貼上下方網址，選擇儲存位置，完成後按Open開啟資料夾。
  3. 由左下角Git分支選單切換至workshop/tcb-2026，確認檔案總管看得到bank-source、samples、specs與prompts。
Git: Clone · Repository URL
https://github.com/nicholas-yahung-chien/tcb-bob-workshop.git

也可下載教材ZIP，解壓後使用File → Open Folder開啟。請使用新的資料夾保存本次成果。

Step 2 · 認識Bob輸入介面

  1. 開啟IBM BOB面板，按「＋」建立New Task。
  2. 點輸入框下方的模式選單（初始可能顯示Agent），依任務選Ask、Plan、Agent或pp4z的Z Code／Z Architecture。
  3. 輸入@並從清單選取檔案，確認附件已加入，再貼上頁面的Prompt。也可把檔案從檔案總管拖入輸入框。
  4. 按送出；遇到檔案寫入或執行命令的Permissions要求，核對內容後核准。完成後開啟output中的檔案檢查結果。

Step 3 · 檢查環境與準備pp4z來源

在Bob模式選單選取 Agent，用 @ 加入下方Prompt列出的檔案，再貼上內容送出。

準備本機工作區 · Agent
請閱讀AGENTS.md，確認目前工作區為教材根目錄。
先執行python scripts/preflight.py，再執行python scripts/prepare_z.py。Windows若只有py指令，使用py -3。
只建立output/z-lab內的閱讀副本，不修改bank-source、samples、tests或scripts。檔案已修改時不要覆蓋。
完成後列出CKP02.cbl、CIS14/CIS14.cbl及Copybook所在位置，回報來源雜湊檢查結果。若失敗，指出實際錯誤，不宣稱pp4z或主機執行已通過。

完成後應有output/z-lab/CKP02.cbl、output/z-lab/CIS14/CIS14.cbl及同目錄的.cpy檔。這些閱讀副本保留原始行號；bank-source保留不變。若已有修改過的副本，準備程序會停止以保留內容。

Step 4 · 確認pp4z入口

在模式選單確認Z Code與Z Architecture（部分介面標示Z Architect），並點Bob面板上方的播放圖示Start Workflow，確認可選Explain code與Generate documentation。本機程式解讀使用工作區檔案；跨應用程式分析另需對應的Z Understand專案。

未出現pp4z模式或Workflow時，請先確認套件啟用與登入狀態，參閱常見問題。
