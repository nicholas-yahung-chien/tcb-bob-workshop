# CKP02／CIS14 延伸閱讀


1. **CKP02**：84行的句點結束IF，86行REWRITE對每筆執行；不是靠縮排判斷。83行資料內EOF只跳過轉換，75–76、88–89行READ的AT END才設EOF旗標讓迴圈停止。27–33行R-ID=10+1=11，REDEFINES不增長度；56–58與94–95行將原3–10位移至1–8、9–10補空白，尾端FILLER不參與這項轉換。課程編碼與基準檔案設定見 BOB-GUIDE.md；正式資料集與環境另行確認。

2. **CIS14**：416–436行以PROCESS-OK控制單筆後續查詢、PGM-OK控制寫出與讀下一筆。3100 GU、3200 GNP、條件式3400 GNP透過CBLTDLI與PCB/SSA運作。447–459行GU將GOOD-STATUS或MORE-RESOURCE-NEEDED走資料搬移；SEGMENT-NOT-FOUND只設PROCESS失敗，其餘才同設PGM失敗。473–479行GNP CIA接受前兩種狀態；查無時不設PGM失敗，其他狀態才設PGM失敗。3400 CIX有自己的分支，各 GNP 與 GU 分支要分開查看。FD在29/35/41/47行為300/80/917/1109位。XIDCHK與BRHIDCNV實作未提供，LINKXID/LINKBRH為250–258行工作儲存區內嵌參數，非同名COPY檔；CALL字面值不能證明繫結選項。

3. **日期**：1161–1180行先在數字條件下，分別檢查年、月、日範圍；不是完整曆法，例如2月31日仍在獨立區間內。1182–1187行分段取CURRENT-DATE並以YYYYMMDD數值減10000；20240229−10000=20230229，是不存在的曆法日期，不能稱為減365天。不同執行日期可能使N25判斷不同，測試需固定日期假設。

4. **影響**：CKP02無直接外部CALL；CIS14明示CBLTDLI、XIDCHK、BRHIDCNV。識別規則變更的候選點包括CKP02移位邏輯、CIS14檢核與外部參數。兩支沒有互相直接CALL，不代表沒有排程或資料相依；缺JCL與外部實作，整體影響還需要補上排程與資料相依。SYSOCP31 和 STANCVT 可以在閱讀各自來源後接著分析。

本文件為選做來源審閱。CIS14 不直接套用 IMSCKP／IMSEVT 的教學 DBD／PSB；未具備原相依時不宣稱完整編譯或執行。第 05 單元可檢查呼叫所用 PCB 與相對應狀態、錯誤後是否繼續，以及 DISPLAY 與實際 ABEND 的差別；採用修改仍依學員分析，不提供固定掃描數。
