# CKP02／CIS14 加深題：講師審訂答案

依來源逐項核對的精簡答案；Bob原始回答與人工修正的差異見驗證報告。這是靜態分析，沒有主機執行結果。

1. **CKP02**：84行的句點結束IF，86行REWRITE對每筆執行；不是靠縮排判斷。83行資料內EOF只跳過轉換，75–76、88–89行READ的AT END才設EOF旗標讓迴圈停止。27–33行R-ID=10+1=11，REDEFINES不增長度；56–58與94–95行將原3–10位移至1–8、9–10補空白，尾端FILLER不參與這項轉換。實體資料集組織與主機code page待確認。

2. **CIS14**：416–436行以PROCESS-OK控制單筆後續查詢、PGM-OK控制寫出與讀下一筆。3100 GU、3200 GNP、條件式3400 GNP透過CBLTDLI與PCB/SSA運作。447–459行GU將GOOD-STATUS或MORE-RESOURCE-NEEDED走資料搬移；SEGMENT-NOT-FOUND只設PROCESS失敗，其餘才同設PGM失敗。473–479行GNP CIA接受前兩種狀態；查無時不設PGM失敗，其他狀態才設PGM失敗。3400 CIX有自己的分支，不能概括所有GNP與GU相同。FD在29/35/41/47行為300/80/917/1109位。XIDCHK與BRHIDCNV實作未提供，LINKXID/LINKBRH為250–258行工作儲存區內嵌參數，非同名COPY檔；CALL字面值不能證明繫結選項。

3. **日期**：1161–1180行先在數字條件下，分別檢查年、月、日範圍；不是完整曆法，例如2月31日仍在獨立區間內。1182–1187行分段取CURRENT-DATE並以YYYYMMDD數值減10000；20240229−10000=20230229，是不存在的曆法日期，不能稱為減365天。不同執行日期可能使N25判斷不同，測試需固定日期假設。

4. **影響**：CKP02無直接外部CALL；CIS14明示CBLTDLI、XIDCHK、BRHIDCNV。識別規則變更的候選點包括CKP02移位邏輯、CIS14檢核與外部參數。兩支沒有互相直接CALL，不代表沒有排程或資料相依；缺JCL與外部實作，不能宣判全系統影響已完整。未在本題讀取的SYSOCP31、STANCVT用途不從名稱猜測。
