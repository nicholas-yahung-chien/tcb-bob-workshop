# 可以怎麼開發這項需求

目前 CKP02 讀入檔案後會直接回寫，所以要讓業務先看結果，可以先增加一支只讀的 COBOL 程式，算出哪些資料會改、共有幾筆。正式執行時則記錄當次實際處理的數字，用 DISPLAY 印出。這是供討論的做法，不是已完成的程式。

比較重要的是讓試跑與正式跑使用同一版資料，並留下可找出差異的依據。若只留兩個總數，即使發現不一致，也不知道是哪幾筆。拆成兩項作業時，資料不能只放在 && 暫存檔，還要決定保存位置、誰確認及如何開始正式跑。

預計會涉及新增預覽程式、正式計數與差異比對，以及相應作業整合。程式名稱、明細格式與保存期限還要討論。既有重跑會再改的行為先保留；沒有防重機制的風險另行設計，不能偷偷改成新的業務規則。

前面執行 RUN 是了解原版，後面的 CKP02H 是程式品質練習，兩者都不代表這項預覽需求已實作。可先完成設計決策，再另排開發與執行驗證。
