# IDSHIFT COBOL 延伸測試計畫

本測試針對 `samples/cobol/IDSHIFT.cbl`，每筆輸入固定為 400 bytes。識別欄位位於第 1–10 bytes；只有前兩個 bytes 為 `00`，且第 14–16 bytes 不是 `EOF` 時，才把原識別欄位第 3–10 bytes 移到前八個 bytes，並在末尾補兩個空白。第 11–400 bytes 應保持不變。

| 案例 | 輸入重點 | 預期結果 | 判定方式 |
|---|---|---|---|
| 正常轉換 | ID 為 `0012345678`，第 14–16 bytes 不是 `EOF` | ID 為 `12345678  ` | 比對完整 400 bytes |
| 資料內 EOF | ID 為 `0012345678`，第 14–16 bytes 為 `EOF` | 整筆不變 | 比對完整 400 bytes |
| 前綴不符 | ID 為 `AB12345678` | 整筆不變 | 比對完整 400 bytes |
| EOF 位於相鄰位置 | 第 12–14 bytes 為 `EOF`，第 14–16 bytes 不是 `EOF` | 仍依規則轉換 ID | 比對完整 400 bytes |
| 其餘資料保留 | 第 11–400 bytes 放入可辨識內容 | 只有第 1–10 bytes 改變 | 先複製輸入為預期值，只改預期 ID，再比對完整記錄 |
| 連續轉換兩次 | 初始 ID 為 `0000123456` | 第一次為 `00123456  `，第二次為 `123456    ` | 每次呼叫後分別比對完整 400 bytes |
| 空白 ID | ID 為十個空白 | 整筆不變 | 比對完整 400 bytes |

`TESTSHIFT-EXT.cbl` 會逐一執行以上案例。任一案例失敗時顯示案例名稱並累計錯誤；全部完成後，錯誤數為零時回傳碼為 0，否則為 8。

這份程式尚未在本課程環境編譯或執行。實際驗證需要可呼叫 `IDSHIFT` 的 COBOL 編譯與連結環境，並讓編譯器能找到 `IDREC.cpy`。執行後應補上編譯器版本、命令或 JCL、回傳碼與輸出；Python 測試結果不能代替這份 COBOL 測試的執行證據。
