# 預覽需求的影響分析參考

## 直接要檢視的程式

z-lab/CKP02.cbl 第 73 行 OPEN I-O、第 86 行 REWRITE 是預覽只讀設計的關鍵；第 82–84 行為轉換條件，第 94–95 行為移位。只把輸出訊息命名為「預覽」並不能防止原程式寫回。可新增只讀程式或設計明確模式，採用哪一項仍須確認。

正式計數應在實際讀取、判斷及寫入處累計，區分讀入、符合條件、實際改變及回寫筆數。原版每筆均 REWRITE，實際改變筆數不等於回寫次數。課程回答 DISPLAY 足以呈現計數，但未決定差異明細格式。若試跑與正式不一致，要以同一輸入版本與保留的前後資料定位記錄，不能只重掃正式結果猜測。

## 作業與資料

新增程式將影響編譯、連結、DD 及作業啟動方式。已提供 z-tests/run.jcl 是 15 步基準，並非預覽作業。其 &&WORK、兩次快照及預期資料供測試，不是跨作業的正式保存方案。需另確認永久副本、批次識別、人工確認與後續清理。

主機連線 tcb-rse／IBM-1371、來源／測資 IBM-937 與 CODEPAGE(937),DBCS 是課程已知設定；正式 INPUT1、存取控制、排程及下游資料契約仍待確認。重跑可能再轉換，正式無防重機制的回答不等於已同意新增某一防重方案。

## 其他程式與本節界線

IDSHIFT 是選做的記憶體轉換比較例，不是需求的新程式；Python normalizer 是另選的 ASCII bytes 模型，不是本需求預定實作。CIS14 的 IMS 呼叫不能證明它與 CKP02 在正式系統相連；IMSRUN 的串接則是明確提供的教學模型。未提供的 Java／API 或排程相依不自行推論。

第 05 單元的 CKP02H 只改善本機檔案錯誤處理，再做 ZCodeScan；不實作預覽、不產生 JCL、不上傳或執行。其掃描報告不證明需求已開發或執行正確。
