# RC 4 延伸練習的紀錄參考

本檔對應第 04 單元 RC4-LAB.md，不適用第 05 的本機 CKP02H。原版 job ID、完整 CCKP/SYSPRINT 路徑、所有警告代碼及訊息由學員填入，不能只憑最高 RC 判斷失敗。

| 分析項目 | 紀錄方式 |
|---|---|
| 序號或格式警告 | 引用完整訊息、程式序號欄及編譯選項，說明為何發生。 |
| 控制流程警告 | 追查 PERFORM、段落結束與 STOP RUN，引用實際診斷及來源。 |
| 摘要訊息 | 指向前面的警告，不新增假定根因。 |
| 修正建議 | 說明最小改動；不關閉全部警告或覆寫 RC。 |

若選做，依指引另存 CKP02R、run-rc0.jcl 及 review.md；修正後用新的 job ID 寫 test-report.md。只有實際清單證明原警告消失、15 步均 RC 0、兩次各七筆完整比對通過與空檔 RC 0，才能寫修正版達標。本文未提供學員實測結論，也不提供可以跳過審閱的通用修正版。
