# CR-01 實作清單參考答案

- [ ] 分析｜主機開發｜依賴CKP02與需求｜核對400字元、11位R-ID群組、IF/REWRITE範圍；驗收：行號與欄位表一致。
- [ ] 分析｜整合/DBA｜依賴系統清單｜七領域逐項標已知/未知，無Java/API/DB schema不補造。
- [ ] 設計｜架構/業務｜依賴計數定義｜dry-run回原副本、written=0；write回轉換副本；驗收：介面契約明確。
- [ ] 實作｜開發｜依賴核定規格｜只寫output純函式；全批先驗證、不改caller、不做I/O。
- [ ] 測試｜QA｜依賴合成400 bytes測资｜正常、EOF、非00、空批、長度錯誤、尾部保留、重跑、dry-run；驗收：獨立測試與學員測試通過。
- [ ] 測試｜主機QA｜依賴正式環境｜EBCDIC/DBCS、JCL、檔案鎖、REWRITE、返回碼、中斷回復；本機模型不能代替。
- [ ] 部署｜維運｜依賴核准變更單/窗口｜備份、hash、權限、避免並行、排程暫停；驗收：同一來源版本且可追蹤。
- [ ] 回復｜維運/業務｜依賴核驗備份｜停止後續消費、還原一致版本、核對筆數/hash，重新排程前確認非冪等風險。

此清單是待辦模板；勾選必須附實際證據，不因Bob生成文件就視為已執行。
