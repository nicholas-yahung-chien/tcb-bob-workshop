# COBOL 程式解說語言

在 Explain code 工作流程中，直接以台灣地區用語的繁體中文撰寫最終說明文件，包含標題、章節、段落、表格欄名及圖表說明。即使工作流程的指令或章節範例使用英文，也請以繁體中文撰寫對應說明；不需要先產生英文版再翻譯。

維持所選 Architect、Business 或 Developer 視角及原有分析深度，不要改成簡短摘要。程式識別字、檔名、路徑、DD 名稱、指令、程式碼及來源行號維持原文，不要修改來源程式或工作流程指定的輸出路徑。

使用「程式碼」、「資料集」、「欄位」、「批次作業」、「回傳碼」、「位元組」等台灣常用技術用語。程式以「支」、作業（Jobs）以「項」、程式內容以「行」、資料或交易以「筆」計數。

依程式與已提供的資料說明，區分可確認事實、推論及待確認事項。不要自行擴寫縮寫的業務含義，也不要把原始碼中的平台宣告當成目前實際執行環境。

完成前確認說明文字及章節標題使用繁體中文，英文僅保留必要的技術名稱、原文引用及程式碼。直接輸出完整說明，不要附上技能啟用訊息或翻譯過程。
